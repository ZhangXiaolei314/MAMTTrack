# 🚀 MAMTTrack

Official repository for the paper:

**MAMTTrack: Efficient Infrared Anti-UAV Tracking via a Unified Relative Motion Prior**

## ✨ About

MAMTTrack is an efficient infrared anti-UAV tracking framework that uses a Unified Relative Motion Prior (URMP) shared by a Motion-to-Appearance Fusion Module (M2A-FM), a Logarithmic Retrieval Memory Bank (LRMB), and Motion-Guided Auxiliary Search (MGAS) to improve appearance discrimination, historical memory reliability, and recovery after local search failure.

## 📁 Results

The tracking results on the **AntiUAV**, **AntiUAV410**, and **CST AntiUAV** test sets are provided in the [`Results/`](Results/) folder.
